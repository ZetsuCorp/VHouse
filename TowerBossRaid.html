VHOUSE

TOWER BOSS RAID

Game Design Notes

1. Concept

Tower Boss Raid is a new VHouse battle mode inspired by Mortal Kombat's tower battles, using a simplified survival system.

2. Index Integration

  • A new Tower Boss Raid button appears in the background of the Index map.
  • The button opens a dedicated Tower Boss Raid page.

3. VCard Entry

  • Players select a VCard to enter the tower.
  • The battle uses the VCard's existing ATK and DEF stats.

4. Battle System

  • Simple survival-based battle loop.
  • Battle mechanics will use ATK and DEF.
  • Exact combat calculations: To be defined.
  • Survival rules: To be defined.

5. Pending Design Decisions

  • Battle progression.
