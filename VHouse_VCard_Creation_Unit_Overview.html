VCARD CREATION UNIT

The VCard Creation Unit is VHouse's character-NFT creation and development system. It brings card design, blockchain ownership, editable character metadata, visual customization, and character-linked SOL value into one game interface.

Character NFT engine Solana Token-2022 IPFS-backed artwork & metadata No collection required

The Two Main Units

✦
New character

MINT VCARD

The creation side of VHouse. A new character card combines its team, identity, image, description, level, and combat stats into one complete VCard artwork.

The completed card becomes the NFT artwork. Its JSON metadata is stored through IPFS and linked to a newly minted Solana Token-2022 NFT.

◇
Existing character

LOAD NFT

The existing-NFT side of VHouse. It identifies supported NFT standards, reads available artwork and metadata, and checks on-chain ownership against the connected Phantom wallet.

UPDATE VCARD

Changes character information and artwork on the existing NFT.

CUSTOMIZE VCARD

Applies visual effects and evolves the character's presentation without replacing its identity.

NFT Identity & Metadata

On-Chain Identity

New VCards are Token-2022 NFTs designed with a single-token supply, non-transferable character ownership, a metadata pointer, and MintCloseAuthority for the mint account.

The character retains its original mint address across supported UPDATE and CUSTOMIZE operations.

Existing NFTs can be recognized as Token-2022 or Metaplex Core when loading. Editing depends on the NFT program and its update authority; Core-specific editing is separate from the Token-2022 update mechanism.

Artwork & Attribute Records

The full rendered VCard PNG and its metadata JSON are stored on IPFS through Pinata. The NFT metadata URI provides access to the JSON through an HTTPS gateway.

The standard JSON attributes array stores character values such as Team, Level, ATK, DEF, and any applied Effect using trait_type and value.

The artwork displays the player's character name; NFT metadata adds the backend prefix “Vcard ” without altering the printed card.

Character Value & Service Fees

Every supported paid UPDATE or CUSTOMIZE adds a small amount of SOL directly to the character NFT's mint account. The player supplies both portions in the transaction: VHouse receives its service share, and the NFT receives its character-value share. Accumulated SOL is not an in-game spending balance.

The VCard Receipt

Each card has two faces: the character art on the front and its NFT information receipt on the back. The receipt keeps technical links outside the main game display.

The unit provides mint-status feedback and a success presentation, with the completed VCard downloadable as a PNG. Updated artwork and metadata produce fresh IPFS records while preserving the existing compatible NFT's mint address.

The Concept

A VCard is a developing game character, not just a static NFT image. Its design, metadata, and associated on-chain value can evolve over time, while VHouse provides one coherent creation and editing experience without requiring every card to belong to a collection.
